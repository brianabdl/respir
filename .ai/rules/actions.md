# Actions

## Regenerate Wayfinder with --with-form, then format

Wayfinder output is committed and generated by the @laravel/vite-plugin-wayfinder plugin with formVariants: true. If you regenerate manually you MUST use `php artisan wayfinder:generate --with-form` — the plain command omits the `.form` variants and instantly breaks existing Auth/settings Form usages (TS2339). The CLI output is also unformatted: run `bun run check:fix` afterwards, then `bun run types:check`.
